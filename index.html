CrossplayCore

Cross-platform multiplayer for Unreal Engine: one API for Steam and Epic Online Services.

CrossplayCore gives you one Blueprint and C++ API for login, lobbies, friends, invites, presence and matches across Steam and Epic Online Services (EOS). Steam players log in to EOS with their Steam account (EOS Connect), so Steam players, Epic players and anyone else with a Product User Id meet in the same EOS lobbies.

No custom GameInstance, GameMode or Online Subsystem is required. The plugin uses the Steamworks and EOS SDKs that ship with the engine, so it runs on its own.

Even better with SteamCore PRO and EOSCore

CrossplayCore uses the Steam and EOS platforms of SteamCore PRO and EOSCore when they are in the project. You configure Steam and EOS once, CrossplayCore's matches run over their networking, and you get their full Blueprint APIs for stats, leaderboards, Workshop, Player Data Storage and more on the same login. See Steam setup and EOS setup.

Features​

FeatureDescription
LoginSteam → EOS Connect, Epic accounts (launcher, saved login, account portal), Device ID and the Dev Auth Tool for PIE.
Crossplay lobbiesCreate, find, join and leave EOS lobbies that every platform shares, with quick match, member events, kick, owner handover, settings changes, lobby chat, join in progress and same platform only.
Typed attributesString, Integer, Float and Boolean lobby and member attributes, and search filters that compare numbers.
Invites and join requestsIn-game invites, offline invites, a list of pending invites, Steam overlay invites and starting the game from an invite.
Friends and presenceSteam or Epic friends with their Product User Id, so they can be invited straight into a crossplay lobby. Friend requests, blocking, avatars and recent players.
Matches over P2PStart a listen server match over EOS P2P (or Steam P2P) from the lobby, and end it to return to the lobby. No ports, no DefaultEngine.ini changes.
Steam lobbiesThe same nodes on Steam lobbies, when EOS is not available or not wanted.
Host migrationKeep the match going when the host leaves, with HostMigrationCore.
ModerationReport players and read their sanctions through EOS, for every platform, and keep sanctioned players out of lobbies.
Online SubsystemThe engine's own Create / Find / Join Session nodes work on top of CrossplayCore.

How it fits together​

A game runs two backends at the same time:

BackendRoleProvides
Steam (platform)Who the player isSteam session ticket for EOS, friends, rich presence, overlay invites, achievements
Epic Online Services (service)The crossplay layerProduct User Id, lobbies every platform shares, in-game invites

The Crossplay Subsystem (a Game Instance subsystem) logs in to both and sends each call to the backend that serves it: lobbies go to EOS when crossplay is active, the friends list and achievements go to Steam. See How it works.

On Linux, the engine has no EOS P2P socket subsystem (SocketSubsystemEOS), so Linux players can't host or join matches over EOS P2P. Everything else works on Linux, including EOS lobbies and matches in Steam lobbies. See Linux.
