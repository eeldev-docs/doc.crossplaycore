Reference

Plugin settings

The settings are in Edit → Project Settings → Plugins, and are saved to Config/DefaultGame.ini.

Crossplay​

Saved under [/Script/CrossplayCore.CrossplaySettings].

Backends​

SettingDefaultDescription
Platform Backend ClassCrossplayBackend_SteamThe platform backend: who the player is, friends, overlay, achievements.
Service Backend ClassCrossplayBackend_EOSThe crossplay service: Product User Id and shared lobbies.

See How it works.

Lobbies​

SettingDefaultDescription
Lobby ServiceAutoWhich lobbies CreateCrossplayLobby and FindCrossplayLobbies use. Auto: EOS lobbies when logged in to EOS, otherwise Steam lobbies. Crossplay: only EOS lobbies, so players on every platform meet. Platform Only: only Steam lobbies, so only Steam players meet, and there is no lobby voice chat. It does not change the login: the backends decide that.
Auto Accept Join RequestsOnJoin the lobby by itself on a join request. Turn off to call JoinCrossplayLobby yourself.

Match​

SettingDefaultDescription
Auto Join MatchOnMembers travel to the owner by themselves when the match starts. Turn off to call Join Match yourself.
Accept Other Platforms In MatchOnLet players with ids from another Online Subsystem into a match hosted from a crossplay lobby. The engine otherwise rejects them with incompatible_unique_net_id.

Voice​

SettingDefaultDescription
Voice Input Starts MutedOffJoin voice chat with the microphone muted.

Login​

SettingDefaultDescription
Epic Account LoginLauncher OnlyWhen players log in with their Epic account: Never, Launcher Only or Always. See Epic accounts.
Allow Device Id LoginOnLog in to EOS anonymously when Steam is not running.
Device Id Display NameEmptyThe display name for Device ID logins. Empty uses the computer's name.

Login | Dev Auth​

SettingDefaultDescription
Use Dev Auth ToolOffLog in with the EOS Developer Authentication Tool. Never in Shipping. See Testing.
Dev Auth Hostlocalhost:6547The address of the tool.
Dev Auth CredentialsPlayer1, Player2, Player3, Player4The credential name for each PIE instance.

Crossplay - Epic Online Services​

Saved under [/Script/CrossplayCoreEOS.CrossplayEOSSettings].

With EOSCore

When EOSCore is in the project, CrossplayCore uses EOSCore's EOS platform and its settings in Project Settings → Plugins → EOSCore Plugin. The platform settings below (Create Platform If Missing, the ids, Client Secret and Enable Voice Chat) are then ignored, even when they are filled in. The scope and lobby settings still apply.

SettingDefaultDescription
Create Platform If MissingOnCreate the EOS platform when no other plugin has created one.
Product IdEmptyFrom the Epic Developer Portal.
Sandbox IdEmptyFrom the Epic Developer Portal.
Deployment IdEmptyFrom the Epic Developer Portal.
Client IdEmptyFrom the Epic Developer Portal.
Client SecretEmptyFrom the Epic Developer Portal.
Request Friends ScopeOnAsk for the player's Epic friends at Epic login. Needs the Friends permission in the client policy. See Scopes.
Request Presence ScopeOnAsk for the player's Epic presence at Epic login. Needs the Online Presence permission in the client policy.
Lobby PresenceOnTie EOS lobbies to the player's Epic presence, so Epic friends can join from the social overlay. Only for players logged in with an Epic account.
Enable Voice ChatOnCreate the EOS platform with voice for lobby voice chat.

When Create Platform If Missing is on and the ids are set, the plugin only reuses an existing EOS platform with the same Product Id and Client Id. Platforms created by other plugins for other products (for example the editor's Fab plugin) are skipped.

See EOS setup.

Example​

Config/DefaultGame.ini
[/Script/CrossplayCore.CrossplaySettings]
LobbyService=Auto
bAutoAcceptJoinRequests=True
bAutoJoinMatch=True
bAcceptOtherPlatformsInMatch=True
bVoiceInputStartsMuted=False
EpicAccountLogin=LauncherOnly
bAllowDeviceIdLogin=True
bUseDevAuthTool=False

[/Script/CrossplayCoreEOS.CrossplayEOSSettings]
bCreatePlatformIfMissing=True
ProductId=...
SandboxId=...
DeploymentId=...
ClientId=...
ClientSecret=...
bRequestFriendsScope=True
bRequestPresenceScope=True
bLobbyPresence=True
bEnableVoiceChat=True
