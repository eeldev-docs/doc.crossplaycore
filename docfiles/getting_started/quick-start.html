Getting Started

Quick Start

Example project

See every step below in a working game in the example project, or try the playable build first.

All nodes are in the Crossplay category. The latent nodes have an On Success and an On Failure pin, and return a Crossplay Error with a Result and a Message.

1. Log in​

Call Crossplay Login once, for example from your GameInstance or main menu. It logs in to Steam and then to EOS with the Steam account, and returns the local player's Crossplay User Id.

Event Init ──► Crossplay Login
                 On Success ──► Print "Logged in as" + Local User
                 On Failure ──► Print Error.Message

Calling it again while logged in returns at once with the same user. See Login for the other ways players can log in.

2. Create a lobby​

The host calls CreateCrossplayLobby with a Crossplay Lobby Settings:

FieldExample
Max Members4
VisibilityPublic
Bucketdefault
Attributesmode = "deathmatch", skill = 1500

3. Find and join it​

Other players call FindCrossplayLobbies with the same Bucket, optionally with filters, and JoinCrossplayLobby with the Lobby Id of a result.

FindCrossplayLobbies  (Bucket: default, Filters: mode == "deathmatch")
  On Success ──► For Each Lobbies ──► JoinCrossplayLobby (Lobby Id)

Bind On Lobby Member Joined, On Lobby Member Left and On Lobby Updated on the Crossplay Subsystem to keep your lobby UI up to date.

4. Start the match​

When everyone is ready, the lobby owner calls StartCrossplayMatch with a map. The map opens as a listen server over EOS P2P, and the other members travel to it by themselves. See Matches.

5. Invite friends​

  • QueryCrossplayFriends gives the friends list. Friends with a Product User Id can be invited with SendCrossplayInvite.
  • Show Invite Overlay opens the Steam invite dialog for the current lobby.

See Invites and join requests.
